# E-Commerce Website – Manual Testing Project

## Project Overview

This project demonstrates manual testing of an e-commerce website using the nopCommerce Demo Store.

The objective is to verify website functionality, identify defects, prepare test scenarios and test cases, and document testing results.

## Application Under Test

* **Website:** https://demo.nopcommerce.com/
* **Testing Type:** Manual Testing
* **Tool Used:** Microsoft Excel

## Modules Tested

1. User Registration
2. Login
3. Product Listing
4. Product Search
5. Shopping Cart
6. Checkout

## Testing Activities

* Prepared 20 test scenarios.
* Designed 21 test cases.
* Performed functional testing.
* Performed positive and negative testing.
* Compared actual results with expected results.
* Identified and documented defects.
* Created an Excel test execution dashboard.
